# Neón Arcade

Página web de una sala de arcade, creada con HTML, CSS y JavaScript sin dependencias de instalación.

## Cómo verla

Abre `index.html` en un navegador. Para publicarla, puedes activar GitHub Pages desde **Settings → Pages** y seleccionar la rama `main` como origen.

## Personalización

- Cambia el nombre y los textos para adaptarlos a tu trabajo.
- Edita las tarjetas de juegos en `index.html`.
- Modifica los colores desde las variables CSS definidas en `:root`.
