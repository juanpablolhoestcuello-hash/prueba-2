# Pixel Club — Página de arcade

Plantilla web adaptable para presentar un arcade, sus juegos y la experiencia para visitantes. Está construida con HTML, CSS y JavaScript, sin dependencias de instalación.

## Cómo verla

Abre `index.html` en un navegador. Para publicarla con GitHub Pages, ve a **Settings → Pages** y selecciona la rama `main` como origen.

## Personalización

- Cambia el nombre **Pixel Club** por el nombre de tu arcade o trabajo.
- Edita los títulos y descripciones de las tarjetas de juegos.
- Cambia la paleta editando las variables CSS al principio de `index.html`.
- Sustituye emojis e ilustraciones por imágenes propias si lo deseas.
